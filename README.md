# Nota Alumno

## Descripción
¿Cúal es la función de este programa?
- A partir de un array de notas permite saber:
  1. Encontrar la nota más alta de todas sus notas.
  2. Saber cuantas veces se repite la nota más alta e indicar por pantalla las veces que se repite.
  3. Obtener la nota media de sus notas y mostrar la nota media por pantalla.
  4. Indicar por pantalla si el alumno ha aprobado o suspendido segun su nota media, siempre que sea > 5.
## Ejecución del programa
¿Cómo ejecuto el programa?
Hay 2 maneras de poder ejecutar el programa:
### Terminal
Para ejecutar el programa en la terminal necesitaremos saber:
1. Ruta del archivo de NotasAlumno.java.
2. 2. Desde la terminal de nuestro SO poner el siguiente comando:
   - Debemos estar en la misma carpeta que el archivo de java "javac NotasAlumno.java".
3. Después hay que poner "java NotasAlumno".
### Consola de IDE
Este es el más sencillo, simplemente agregaremos nuestro archivo java al IDE que sea compatible y le daremos al botón de ejecutar.
